## ก่อนคุยเพื่อน

เตรียม 3 อย่างนี้ไปพอ:

1. ตาราง commitment ของนภัทรฉบับล่าสุด

    - Auth + Audit Full-stack
    - D&M Dashboard Slice
    - NTV ใช้ Live Data ถ้าเพื่อนพร้อม, Mock Data ถ้ายังไม่พร้อม
2. คำถามที่ต้องให้เพื่อนตอบต่อ feature

    - Owner คือใคร
    - Demo ปลายเทอมคืออะไร
    - ส่ง API/contract/fixture อะไรให้นภัทรได้ และเมื่อไร
    - อะไรตัดไป P2
    - ถ้าไม่ทัน ใช้ Mock Data ได้ไหม
3. รายการที่นภัทรต้องขอจากเพื่อน
    
    - Inventory: device/interface contract และ fixture
    - Discovery: LLDP/CDP observation contract หรือ fixture
    - Config/CIS/Settings: audit event ที่แต่ละ feature จะเรียก
    - ทุกคน: deadline ภายในของตนเอง

3. ล็อก dependency และ fallback mock data
