# Sequence Diagram ของนภัทร — Mermaid ขาวดำ

แปลง 5 ภาพจาก `../diagrams.json` เมื่อ 16 ตุลาคม 2569 โดยคงผู้ร่วมสื่อสาร ข้อความลูกศร ลำดับการทำงาน และเงื่อนไข `alt` / `opt` จากชุด Draw.io เดิม ใช้การจัดวางของ Mermaid พร้อมหัวผู้ร่วมสื่อสารด้านบนและด้านล่าง

ปรับรูปแบบตามภาพของเพื่อนสำหรับรายงาน: พื้นขาว ตัวอักษรและลูกศรสีดำ กล่องหัวผู้ร่วมสื่อสารและ Note สีขาวขอบดำ Lifeline เส้นทึบสีดำ กรอบเงื่อนไขเส้นประสีดำ และ Activation สีเทา ไม่มีสีม่วงหรือสีเหลือง ชุดโค้ด Mermaid ทุกไฟล์มี Theme และรูปแบบเส้นนี้ในตัว

## ตรวจสอบ

ผ่านการ Parse และ Render ด้วย Mermaid 11.12.0 ตรวจข้อความลูกศรตามลำดับเทียบกับต้นฉบับครบ 85 รายการ และไม่พบข้อความออกนอกขอบภาพ ตรวจสี Fill/Stroke ขององค์ประกอบที่มองเห็นทั้งหมดแล้วเป็นขาวดำหรือเทา ไม่มีสีอื่น รายละเอียดอยู่ใน `render-qa.json` เปิดตรวจภาพ PNG ทั้ง 5 ภาพหลัง Render แล้ว

Dashboard และการตรวจสิทธิ์ของ Topology เป็นลำดับตามการออกแบบ ไม่ใช่การยืนยันว่า Implementation ทำครบแล้ว คงเลขรูปตามชุดเดิม ซึ่งเลข 3.12 ใน Doc ออนไลน์ยังซ้ำกับรูปของเพื่อน ชุดนี้ไม่ได้แก้เอกสารออนไลน์

ไฟล์ Markdown/Mermaid ใช้คำสั่งมาตรฐานของ Sequence Diagram; สีและระยะจริงใน Obsidian อาจต่างจากภาพที่แนบตาม Mermaid รุ่นที่ฝังมาและ Theme ของ Vault ส่วน SVG/PNG/หน้าเว็บตัวอย่างใช้ผล Render ที่ตรวจแล้ว

สร้างซ้ำด้วย `node build-mermaid.cjs` ใช้ JSON ของชุดเดิมเป็นข้อมูลต้นทาง และประมวลผลแผนภาพในหน้าท้องถิ่น โดยดาวน์โหลดเฉพาะตัว Mermaid Renderer
