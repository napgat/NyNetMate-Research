# Process Flow

ลำดับขั้นตอนการดำเนินงานวิชาโครงงาน

## ขั้นตอนการดำเนินการ : Project 1
1. **แจ้งหัวข้อ** บนเว็บไซต์ [ce.kmitl.ac.th](https://ce.kmitl.ac.th)
   - อาจารย์ที่ปรึกษา: สร้างหัวข้อโครงงาน
   - นักศึกษา (หัวหน้ากลุ่ม): สร้างกลุ่มโครงงาน
   - นักศึกษา (สมาชิก): ยืนยันตอบรับคำเชิญเข้าร่วมกลุ่ม
   - นักศึกษา (หัวหน้ากลุ่ม): ร้องขอการทำโครงงาน (หลังจากตกลงกับ อ.ที่ปรึกษาแล้ว)
   - อาจารย์ที่ปรึกษา: ตอบรับการร้องขอทำหัวข้อโครงงาน
2. **เข้าพบอาจารย์ที่ปรึกษา**: ปรึกษาและส่งรายงานความคืบหน้าตามกำหนด
3. **ส่งร่างรายงานโครงงาน**: ส่งรายงานโครงงาน (รูปแบบคล้ายปริญญานิพนธ์) ให้อาจารย์ที่ปรึกษาพิจารณา
4. **ส่งงานขั้นสุดท้าย**: ส่งรายงานโครงงาน และไฟล์นำเสนอตามผู้ประสานงานวิชาโครงงานประกาศ
5. **สอบนำเสนอ**: ทำการสอบนำเสนอต่อหน้าคณะกรรมการ

## ขั้นตอนการดำเนินการ : Project 2
*(เริ่มต้นหลังจากสอบผ่านรายวิชา Project 1 แล้ว)*

1. **เข้าพบอาจารย์ที่ปรึกษา**: ปรึกษาและส่งรายงานความคืบหน้าตามกำหนด
2. **ส่งร่างปริญญานิพนธ์**: ให้อาจารย์ที่ปรึกษาพิจารณา
3. **ส่งงานสำหรับการสอบ**: ส่งร่างปริญญานิพนธ์ และไฟล์นำเสนอตามผู้ประสานงานวิชาโครงงานประกาศ
4. **Deploy โครงงาน**: Deployment โครงงานใน Server ที่ภาควิชากำหนด (CE Cloud)
5. **สร้างหัวข้อ**: บนเว็บไซต์ [kip.kmitl.ac.th](https://kip.kmitl.ac.th)
6. **สอบนำเสนอ**: ทำการสอบนำเสนอต่อหน้าคณะกรรมการ
7. **สาธิตโครงงาน**: สาธิตโครงงานตามที่ภาควิชากำหนด (เช่น งานแสดงผลงานคณะ Project Day)
8. **ส่งงานฉบับสมบูรณ์**: ส่งปริญญานิพนธ์ฉบับสมบูรณ์ เอกสารประกอบ และคู่มือต่างๆ ตามที่ผู้ประสานงานวิชาโครงงานกำหนด
9. **อัปโหลดไฟล์**: นักศึกษา (หัวหน้ากลุ่ม) ส่งปริญญานิพนธ์ บนเว็บไซต์ [ce.kmitl.ac.th](https://ce.kmitl.ac.th)
