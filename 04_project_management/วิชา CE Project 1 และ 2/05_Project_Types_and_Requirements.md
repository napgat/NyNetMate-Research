# Project Types & Requirements

ประเภทโครงงานและข้อกำหนดเฉพาะเจาะจง

## ประเภทโครงงาน (Project Topic Type)
- **แบบที่ 1**: HW+SW (Hardware and Software)
- **แบบที่ 2**: SW_Dev (Software Development เช่น Mobile App, Web App, Software Application)
- **แบบที่ 3**: Research (งานวิจัย)

---

## หัวข้อการประเมินและข้อกำหนดเฉพาะสำหรับประเภทแบบที่ 2 : SW_Dev

### หัวข้อการประเมินหลัก
1. ศึกษาทบทวนข้อกำหนดที่ควรมี และจำเป็นต้องมี (เหมาะสมกับวุฒิ วศ.บ. คอมพิวเตอร์)
2. การออกแบบ UX/UI
3. การออกแบบ Use Case Diagram / Class Diagram / Sequence Diagram หรือ Diagram แบบอื่นๆ ที่อธิบายการทำงานของระบบและโครงสร้างโปรแกรม
4. การออกแบบโครงสร้างของระบบ Software Architecture Diagram / System Architecture Diagram
5. ความสามารถในการทำงานได้ตามขอกำหนด และ การทดสอบการทำงาน (Unit Testing / Integration Testing หรือ อื่นๆ)
6. การ Deploy และ Integrate ให้เป็นระบบที่ทำงานได้ตามข้อกำหนด

### เงื่อนไขพิเศษเฉพาะรายละเอียดรายงาน / ปริญญานิพนธ์ สำหรับ SW_Dev
หากไม่มี หรือมีไม่ครบจะถูกหักคะแนน เพื่อให้โครงงานมีความสมบูรณ์ (คะแนนนี้จะหักอย่างเดียว แต่ไม่เกิน 5 คะแนน)
โครงงานที่เป็น SW_Dev ต้องมี:
- **ER-Diagram**: ต้องออกแบบอย่างถูกต้องอย่างน้อยระดับ 3NF ห้ามใช้ ID ในตารางที่ไม่ใช้ Entity พื้นฐาน (เช่น ตารางที่เก็บว่าผู้สอนสอนวิชาใด)
- **Use Case Diagram** และ Use Case Description
- **Sequence Diagram**: อย่างน้อยในระดับ Component และต้องเขียนอย่างถูกต้อง

### สำหรับโครงงาน SW_Dev ที่เน้นเรื่อง ML (Machine Learning) ต้องมีเพิ่มเติม:
- ข้อมูลที่มาของแนวทางการแก้ปัญหา และควรมีมากกว่า 1 แนวทางเปรียบเทียบกัน
- ส่วนที่อธิบายอัลกอริทึมหรือเทคนิคที่ใช้งาน
- ลำดับการพัฒนาพร้อมแนวคิด เช่น การวิเคราะห์ผลและปรับปรุงในแต่ละขั้นตอน
- วิธีการวัดผลที่เป็นมาตรฐานทั้งในด้านประสิทธิภาพและประสิทธิผล
- การบอกเครื่องมือที่เลือกใช้พร้อมเหตุผลประกอบชัดเจน
