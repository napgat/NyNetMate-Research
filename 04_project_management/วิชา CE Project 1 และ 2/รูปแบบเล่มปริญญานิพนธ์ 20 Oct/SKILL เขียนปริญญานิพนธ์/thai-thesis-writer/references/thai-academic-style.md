# คู่มือสไตล์ภาษาวิชาการไทย

เป้าหมายคือภาษาที่ชัด กระชับ และเป็นทางการพอเหมาะ ผู้อ่านคือกรรมการที่ต้องอ่านทั้งเล่มและตรวจตรรกะ ประโยคที่ยาวเพื่อให้ดูเป็นวิชาการทำให้ตรรกะเห็นยาก

## สารบัญ

1. หลักการหลัก
2. ปัญหาที่พบบ่อยพร้อมตัวอย่างก่อน-หลัง
3. ศัพท์เทคนิคและการทับศัพท์
4. คำเชื่อมและโครงย่อหน้า
5. คำและสำนวนที่ควรเลี่ยง
6. การตรวจสำนวนโดยไม่เปลี่ยนความหมาย

---

## 1. หลักการหลัก

- **บุรุษและน้ำเสียง** งานวิจัยเรียกตนเองว่า "ผู้วิจัย" งานโครงงานวิศวกรรมใช้ "ผู้จัดทำ" หรือ "คณะผู้จัดทำ" ตามคู่มือและจำนวนผู้จัดทำ ใช้น้ำเสียงเป็นกลาง ไม่ใช้ "ผม" "ดิฉัน" "เรา" ไม่ใช้อารมณ์หรือคำเกินจริง (เช่น "อย่างมหาศาล" "แน่นอนที่สุด")
- **หนึ่งย่อหน้าหนึ่งประเด็น** ประโยคแรกบอกประเด็น ประโยคถัดไปให้หลักฐานหรือเหตุผล ประโยคสุดท้ายเชื่อมโยงกลับไปที่คำถามวิจัยหรือย่อหน้าถัดไป
- **ประโยคสั้นพอให้ตามได้** ประโยคเดียวไม่ควรมีมากกว่าหนึ่งความคิดหลัก ถ้าต้องใช้ "ซึ่ง" ซ้อนเกินสองชั้น ให้แยกเป็นสองประโยค
- **ใช้กริยาเป็นแกน** ภาษาไทยที่แปลตามโครงภาษาอังกฤษมักเต็มไปด้วย "การ" และ "ความ" ต่อกัน ใช้กริยาแทนเมื่อทำได้
- **สม่ำเสมอ** ใช้คำศัพท์เดียวต่อหนึ่งแนวคิดตลอดเล่ม

## 2. ปัญหาที่พบบ่อยพร้อมตัวอย่างก่อน-หลัง

ตัวอย่างต่อไปนี้เป็นประโยคสมมติเพื่อแสดงวิธีแก้ ไม่ใช่เนื้อหาที่ต้องนำไปใช้

**ประโยคเปิดสำเร็จรูป**
- ก่อน: ในปัจจุบันเทคโนโลยีดิจิทัลได้เข้ามามีบทบาทสำคัญยิ่งในชีวิตประจำวันของมนุษย์
- หลัง: ผู้ใช้อินเทอร์เน็ตในประเทศไทยใช้เวลาออนไลน์เฉลี่ยวันละ [ใส่ตัวเลขและที่มา] ชั่วโมง ทำให้พฤติกรรม... เปลี่ยนไป
- เหตุผล: ประโยคแรกไม่มีข้อมูลให้ตรวจ ประโยคหลังเริ่มจากข้อเท็จจริงที่เจาะจง

**"การ" และ "ความ" ซ้อนกัน**
- ก่อน: การศึกษาการรับรู้ความสามารถของตนเองในการปฏิบัติงานของพนักงานมีความสำคัญต่อการพัฒนาประสิทธิภาพ
- หลัง: การศึกษาว่าพนักงานรับรู้ว่าตนทำงานได้ดีเพียงใด ช่วยให้องค์กรพัฒนาประสิทธิภาพการทำงานได้ตรงจุด
- เหตุผล: ใช้กริยา ("รับรู้" "ทำ" "ช่วย") แทนคำนามต่อกัน

**ประโยคยาวซ้อน "ซึ่ง"**
- ก่อน: ผู้วิจัยได้ใช้แบบสอบถามซึ่งสร้างขึ้นจากแนวคิดซึ่งได้ศึกษามาจากงานวิจัยซึ่งเกี่ยวข้องกับเรื่องนี้
- หลัง: ผู้วิจัยสร้างแบบสอบถามจากแนวคิดที่สังเคราะห์จากงานวิจัยที่เกี่ยวข้อง
- เหตุผล: ตัด "ซึ่ง" ที่ไม่จำเป็นและใช้ "ที่" แทน

**ข้ออ้างเกินข้อมูล**
- ก่อน: ผลการวิจัยพิสูจน์ว่าการอบรมทำให้พนักงานมีความสุขมากขึ้น
- หลัง: ผลการวิจัยพบว่าหลังการอบรม พนักงานมีคะแนนความสุขสูงกว่าก่อนอบรมอย่างมีนัยสำคัญทางสถิติ [ตรวจกับค่าจริง]
- เหตุผล: งานวิจัยเชิงประจักษ์ "พบ" หรือ "สนับสนุน" ไม่ใช่ "พิสูจน์" และต้องบอกการเปรียบเทียบให้ชัด

**ผลปนกับอภิปราย (ตัวอย่างโครง 5 บท)**
- ก่อน: พนักงานมีความพึงพอใจสูง (ค่าเฉลี่ย 4.35) ซึ่งแสดงให้เห็นว่าองค์กรบริหารได้ดีเยี่ยม
- หลัง (บทที่ 4): พนักงานมีความพึงพอใจในระดับมากที่สุด (ค่าเฉลี่ย 4.35 ส่วนเบี่ยงเบนมาตรฐาน 0.52) ส่วนการตีความย้ายไปบทที่ 5
- เหตุผล: บทผลรายงานสิ่งที่พบ การตีความและการอ้างเหตุอยู่บทอภิปราย

**ภาษาพูดหรือกำกวม**
- ก่อน: คนส่วนใหญ่ค่อนข้างไม่ค่อยเห็นด้วยกับเรื่องนี้เท่าไร
- หลัง: ผู้ตอบส่วนใหญ่ (ร้อยละ [ใส่ค่าจริง]) ไม่เห็นด้วยกับข้อความนี้

## 3. ศัพท์เทคนิคและการทับศัพท์

- ครั้งแรกที่ใช้ ให้เขียนรูป ภาษาไทย (English term) เช่น ความผูกพันต่อองค์กร (organizational commitment) หลังจากนั้นใช้คำไทยอย่างเดียว ยกเว้นคำย่อที่นิยมแล้ว
- เลือกศัพท์ตามราชบัณฑิตยสภาหรือพจนานุกรมศัพท์ของสาขาเมื่อมี และใช้ให้ตรงกันทั้งเล่ม บันทึกลงคลังคำศัพท์ในไฟล์สถานะ
- ถ้าศัพท์ในสาขาติดใช้ทับศัพท์ (เช่น ซอฟต์แวร์ อัลกอริทึม) ให้ใช้ตามที่นิยมในสาขา แต่ไม่ปนไทยอังกฤษในประโยคเดียวโดยไม่จำเป็น
- ชื่อแบบวัด ทฤษฎี หรือเครื่องมือ ให้ใช้ชื่อตามต้นฉบับ พร้อมอ้างอิง
- คำย่อ บอกคำเต็มเมื่อใช้ครั้งแรก

## 4. คำเชื่อมและโครงย่อหน้า

| หน้าที่ | ตัวอย่างคำเชื่อม |
|---|---|
| ยกหลักฐาน | จากการศึกษาพบว่า / ผลการวิเคราะห์ชี้ว่า / ข้อมูลแสดงว่า |
| สอดคล้อง | สอดคล้องกับ... ซึ่งพบว่า... / ในทำนองเดียวกัน |
| ขัดแย้งหรือตรงข้าม | อย่างไรก็ตาม / ในทางตรงข้าม / ต่างจาก... ที่พบว่า... |
| เหตุผลที่เป็นไปได้ | ทั้งนี้อาจเป็นเพราะ... / ความแตกต่างนี้อาจเกิดจาก... |
| ขยายหรือเพิ่ม | นอกจากนี้ / ยิ่งไปกว่านั้น |
| สรุป | โดยสรุป / กล่าวได้ว่า |

อย่าใช้ "ทั้งนี้" "อย่างไรก็ตาม" ซ้ำทุกย่อหน้า สลับและเลือกให้ตรงหน้าที่จริง

**แบบย่อหน้าอภิปรายผล** (ตัวอย่างโครง)
1. ผลหลักของวัตถุประสงค์นั้นในหนึ่งประโยค
2. สอดคล้องหรือขัดแย้งกับงานใดในบทที่ 2
3. เหตุผลที่เป็นไปได้ พร้อมหลักฐานหรือทฤษฎีรองรับ
4. ความหมายต่อทฤษฎีหรือการปฏิบัติ

## 5. คำและสำนวนที่ควรเลี่ยง

- คำพูดเกินจริง: อย่างยิ่งยวด แน่นอนที่สุด ไม่ต้องสงสัยเลย
- คำกว้างโดยไม่มีข้อมูล: หลายคน ส่วนใหญ่ มากมาย (ใช้ตัวเลข หรือบอกกลุ่มที่ชัดเจน)
- ภาษาพูด: เยอะ แยะ นิดหน่อย ยังไง
- เครื่องหมายอัศเจรีย์และการเน้นอารมณ์
- "ผู้วิจัยคิดว่า" ในส่วนที่ควรมีหลักฐาน ให้ใช้ "ผู้วิจัยเห็นว่า" เฉพาะส่วนอภิปรายที่เป็นการตีความ และตามด้วยเหตุผล
- ประโยคที่ขึ้นต้นด้วย "การที่..." ยาวหลายบรรทัด แยกประโยคแทน

## 6. การตรวจสำนวนโดยไม่เปลี่ยนความหมาย

เมื่อผู้ใช้ส่งร่างมาให้ปรับสำนวน
- รักษาข้อค้นพบ ตัวเลข ชื่อตัวแปร และข้อสรุปของผู้วิจัยไว้ตามเดิม
- ถ้าประโยคกำกวมจนตีความได้สองทาง ให้ถามผู้ใช้ว่าหมายถึงแบบใด อย่าเดา
- แสดงการแก้ที่สำคัญและเหตุผลสั้น ๆ เพื่อให้ผู้ใช้เรียนรู้และตัดสินใจเองได้
- เก็บเสียงของผู้วิจัยไว้ ไม่เปลี่ยนทุกประโยคให้เป็นแบบเดียวกันจนอ่านรู้ว่าเขียนด้วยเครื่องมือ
