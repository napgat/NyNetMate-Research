MyNetMate เก็บรหัสผ่านด้วย **Argon2id password hash** ไม่เก็บ plaintext และไม่เข้ารหัสแบบถอดกลับได้

## Password hash หน้าตาเป็นอย่างไร?
ในตาราง `users` จะมีคอลัมน์นี้:

```
password_hash
```

ค่าที่เก็บมักมีรูปแบบมาตรฐานประมาณนี้:
```
$argon2id$v=19$m=19456,t=2,p=1$<salt>$<hash>
```

ความหมายโดยย่อ:

- `argon2id` = อัลกอริทึมที่ใช้
- `v=19` = เวอร์ชัน
- `m` = ใช้หน่วยความจำเท่าไร
- `t` = ทำซ้ำกี่รอบ
- `p` = ระดับการทำงานขนาน
- `salt` = ค่าสุ่มเฉพาะของ password นี้
- `hash` = ผลลัพธ์ที่เก็บจริง

ไลบรารีจะสร้างและตรวจรูปแบบนี้ให้เอง เราไม่ควรเขียนกระบวนการ hash, salt หรือ verify เอง

## หลักการทำงาน

ตอนสร้างผู้ใช้หรือเปลี่ยน password:

```
Password ที่ผู้ใช้พิมพ์
        ↓
Argon2id + random salt
        ↓
เก็บผลลัพธ์ใน password_hash
```


ตอน Login:

```
Password ที่ผู้ใช้พิมพ์
        ↓
ไลบรารี Argon2id ตรวจเทียบกับ password_hash
        ↓
ตรงกัน = Login ได้
ไม่ตรง = 401
```

ไม่มีขั้นตอน “ถอด hash กลับเป็น password” เพราะ hash เป็น one-way function

## ทำไมไม่เก็บแบบเข้ารหัสหรือ SHA-256?

| วิธี         | เหตุผล                                                              |
| ------------ | ------------------------------------------------------------------- |
| Plaintext    | อันตรายมาก หาก DB รั่ว ผู้โจมตีเห็นรหัสผ่านทันที                    |
| Encryption   | ถอดกลับได้ ถ้า key หลุด password ทั้งหมดอาจหลุด                     |
| SHA-256      | เร็วเกินไป ผู้โจมตีใช้ GPU เดารหัสผ่านได้จำนวนมาก                   |
| bcrypt       | ยังใช้ได้ โดยเฉพาะระบบเก่า แต่มีข้อจำกัดและไม่ใช่ตัวเลือกแรกของเรา  |
| **Argon2id** | ช้าแบบตั้งใจและใช้หน่วยความจำมาก ทำให้การเดารหัสผ่านจำนวนมากแพงขึ้น |
OWASP แนะนำให้ใช้ Argon2id สำหรับ password storage และระบุ baseline ขั้นต่ำ `19 MiB`, `t=2`, `p=1`; ค่าจริงควรทดสอบกับเครื่องที่จะ deploy ก่อน เพราะยิ่งปลอดภัยก็ยิ่งใช้ทรัพยากรตอน Login มากขึ้น

[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)


## Argon2id คืออะไร?

Argon2 คืออัลกอริทึมสำหรับ hash password โดยเฉพาะ มีคุณสมบัติสำคัญคือ **memory-hard**:

> ผู้ใช้ Login หนึ่งครั้งอาจช้าขึ้นเล็กน้อย แต่ผู้โจมตีที่ต้องเดารหัสผ่านล้านครั้งจะต้องใช้ทั้ง CPU และ RAM จำนวนมาก

Argon2 มีสาม variant:

|Variant|ลักษณะ|เหมาะกับ|
|---|---|---|
|Argon2d|ใช้ memory แบบขึ้นกับข้อมูล|Proof-of-work มากกว่า password web app|
|Argon2i|การเข้าถึง memory ไม่ขึ้นกับข้อมูล|Password hashing|
|**Argon2id**|ผสมข้อดีของ i และ d|Password hashing ทั่วไป เช่น MyNetMate|

Argon2id เริ่มด้วยแนวทางแบบ Argon2i เพื่อลดความเสี่ยง side-channel และผสมคุณสมบัติของ Argon2d เพื่อเพิ่มต้นทุนต่อการเดารหัสผ่าน [RFC 9106](https://datatracker.ietf.org/doc/html/rfc9106)

## หลักการเลือกของ MyNetMate

เราเลือก Argon2id เพราะ:

1. เป็นตัวเลือกที่เหมาะกับระบบใหม่ ไม่ต้องรองรับ hash เก่าจากระบบเดิม
2. ป้องกันการเดารหัสผ่านจากฐานข้อมูลที่รั่วได้ดีกว่า fast hash
3. มี salt เฉพาะแต่ละ password ทำให้ password เดียวกันได้ hash คนละค่า
4. ปรับ memory/time cost ได้ตามเครื่องจริงในอนาคต
5. ใช้ได้ตรงกับ Python/FastAPI ผ่านไลบรารีมาตรฐานที่ผ่านการใช้งานจริง

จุดที่ต้องจำให้แม่น:

> **Password ใช้ Argon2id เพราะ password เป็นข้อมูลที่มนุษย์เดาได้ จึงต้อง hash ให้ช้าและใช้ RAM มาก**  
> **Session token ใช้ SHA-256 ได้ เพราะ token ของเราเป็นค่าสุ่ม 256 bits และต้องค้นหาได้เร็วทุก request**

นี่คือคนละงานกัน แม้ทั้งสองอย่างจะเรียกว่า hash ครับ



ทำไมไม่ใช่ bcrypt?
`bcrypt` ยังเป็น password-hashing algorithm ที่ปลอดภัยและใช้ได้จริง โดยเฉพาะระบบเดิมที่มี password hash อยู่แล้ว เพราะการเปลี่ยนอัลกอริทึมทันทีอาจกระทบผู้ใช้ทั้งหมด แต่มีข้อจำกัดสำคัญคือรับ password ได้จริงเพียง 72 bytes และเน้นเพิ่มต้นทุนด้าน CPU เป็นหลัก ขณะที่ผู้โจมตีสมัยใหม่สามารถใช้ GPU เดารหัสผ่านจำนวนมากได้มีประสิทธิภาพกว่า `Argon2id` ซึ่งออกแบบให้ใช้ทั้งเวลาและหน่วยความจำ (`memory-hard`) ทำให้การเดารหัสผ่านแบบขนานมีต้นทุนสูงกว่า สำหรับ MyNetMate ที่เป็นระบบใหม่ ไม่มีภาระต้องรองรับ hash เก่า และต้องการเลือกมาตรฐานที่เหมาะกับการเก็บ password ตั้งแต่ต้น จึงเลือก `Argon2id` แทน โดย OWASP ก็แนะนำ Argon2id เป็นตัวเลือกแรก และให้ใช้ bcrypt เป็นทางเลือกเมื่อ Argon2id ใช้ไม่ได้หรือมีข้อจำกัดจากระบบเดิม [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
