# คู่มือระเบียบวิธีวิจัย เครื่องมือ และสถิติ

ใช้เมื่อเขียนบทที่ 3 และบทที่ 4 หรือเมื่อผู้ใช้ถามเรื่องเครื่องมือและสถิติ ค่าเกณฑ์ที่ให้ไว้เป็นแนวปฏิบัติที่พบบ่อยในงานวิจัยไทย สถาบันหรือสาขาอาจกำหนดต่างไป ให้ตรวจกับอาจารย์ที่ปรึกษา

เลือกเฉพาะวิธีที่สอดคล้องกับวัตถุประสงค์จริง งานพัฒนาซอฟต์แวร์ใช้ `software-engineering-thesis.md` สำหรับเกณฑ์ยอมรับและการทดสอบ ไม่ต้องเพิ่มแบบสอบถาม การสุ่มตัวอย่าง หรือสถิติทดสอบสมมติฐานหากงานไม่ได้ใช้วิธีเหล่านั้น รูปแบบตารางและการรายงานใช้ `format-*.md` หรือข้อกำหนดที่ยืนยันก่อนค่าทั่วไปในไฟล์นี้

## 1. เลือกรูปแบบการวิจัยจากวัตถุประสงค์

| วัตถุประสงค์ขึ้นต้นด้วย | รูปแบบที่มักเหมาะ |
|---|---|
| เพื่อศึกษาระดับ / สภาพ | สำรวจ (descriptive survey) |
| เพื่อเปรียบเทียบระหว่างกลุ่ม | เปรียบเทียบ (comparative) หรือกึ่งทดลอง |
| เพื่อศึกษาความสัมพันธ์ / ปัจจัยที่มีผล | สหสัมพันธ์ / การถดถอย / โมเดลสมการโครงสร้าง |
| เพื่อศึกษาผลของวิธีการหรือโปรแกรม | ทดลองหรือกึ่งทดลอง (ก่อน-หลัง มีกลุ่มควบคุม) |
| เพื่อทำความเข้าใจประสบการณ์ / ความหมาย | เชิงคุณภาพ (สัมภาษณ์เชิงลึก กรณีศึกษา ชาติพันธุ์วรรณนา) |
| เพื่อพัฒนา... และประเมินผล | วิจัยและพัฒนา (R&D) |
| ต้องการทั้งตัวเลขและความลึก | แบบผสม |

ถ้าวัตถุประสงค์ใช้คำว่า "ปัจจัยที่ส่งผล" แต่ข้อมูลเก็บครั้งเดียวด้วยแบบสอบถาม ให้ระวังการสรุปเป็นเหตุและผล ข้อมูลภาคตัดขวางบอกได้เพียงความสัมพันธ์

## 2. ขนาดกลุ่มตัวอย่างและการสุ่ม

**สูตรและตารางที่พบบ่อย**
- Taro Yamane: n = N / (1 + N·e²) โดย N คือขนาดประชากร e คือความคลาดเคลื่อนที่ยอมรับ (มักใช้ 0.05) ใช้ได้เมื่อรู้ขนาดประชากรจำกัด
- Krejcie & Morgan: ใช้ตารางสำเร็จรูปจากขนาดประชากร ที่ระดับความเชื่อมั่น 95%
- Cochran: ใช้เมื่อไม่ทราบขนาดประชากร หรือประชากรใหญ่มาก
- G*Power: คำนวณขนาดตัวอย่างจากอำนาจการทดสอบ (power) ขนาดอิทธิพล (effect size) และระดับนัยสำคัญ เหมาะกับงานทดสอบสมมติฐานและงานทดลอง
- โมเดลสมการโครงสร้างและการวิเคราะห์องค์ประกอบ มักอิงจำนวนตัวอย่างต่อพารามิเตอร์หรือตัวแปรสังเกตได้ (เช่น 10-20 เท่า) ควรอ้างแหล่งที่ใช้ในงานนั้นจริง

**วิธีสุ่ม** ความน่าจะเป็น (สุ่มอย่างง่าย แบ่งชั้น หลายขั้นตอน กลุ่ม เป็นระบบ) หรือไม่อิงความน่าจะเป็น (เจาะจง โควตา สะดวก ลูกโซ่) งานที่สรุปอ้างอิงไปยังประชากรควรใช้วิธีที่อิงความน่าจะเป็น ถ้าใช้วิธีสะดวก ให้ระบุข้อจำกัดในบทที่ 5

ในหัวข้อกำหนดขนาดตัวอย่าง ให้รายงานเฉพาะพารามิเตอร์ที่วิธีที่เลือกใช้ต้องการ พร้อมแหล่งที่มาและผลคำนวณจริง เช่น ใช้สูตร Yamane จึงระบุ N และ e; ใช้ G*Power ให้ระบุชนิดการทดสอบ effect size, power และระดับนัยสำคัญตามที่ใช้ วิธีที่ใช้เมื่อไม่ทราบ N ไม่ต้องแต่ง N ขึ้นมา ไม่บังคับ N/e กับทุกวิธีหรืองานเชิงคุณภาพ หากข้อมูลที่จำเป็นยังขาดให้ใส่ `[ใส่ค่าจริง: พารามิเตอร์และที่มา]`

## 3. การสร้างและตรวจเครื่องมือ

**ขั้นตอนสร้างแบบสอบถาม** ศึกษาแนวคิดและงานที่เกี่ยวข้อง → นิยามตัวแปรเชิงปฏิบัติการ → ร่างข้อคำถามให้ครอบคลุมทุกองค์ประกอบ → ให้ผู้เชี่ยวชาญตรวจ → ปรับ → ทดลองใช้ → วิเคราะห์ → ปรับเป็นฉบับจริง

**ความเที่ยงตรงเชิงเนื้อหา (IOC)** ผู้เชี่ยวชาญ 3-5 คน (มักอย่างน้อย 3) ให้คะแนนแต่ละข้อ +1 (สอดคล้อง) 0 (ไม่แน่ใจ) −1 (ไม่สอดคล้อง) IOC = ΣR / N เกณฑ์ที่พบบ่อยคือข้อที่ได้ 0.50 ขึ้นไปถือว่าใช้ได้ ข้อที่ต่ำกว่าให้ปรับหรือตัด

**ความเชื่อมั่น** ทดลองใช้กับกลุ่มที่คล้ายกลุ่มตัวอย่างแต่ไม่ซ้ำกัน (มักประมาณ 30 คน) ใช้สัมประสิทธิ์แอลฟาของครอนบาค เกณฑ์ที่พบบ่อยคือ 0.70 ขึ้นไป (บางงานเคร่งถึง 0.80) สำหรับแบบทดสอบที่ตอบถูก-ผิด ใช้ KR-20 และอาจต้องรายงานค่าความยากง่ายและอำนาจจำแนกด้วย

**ค่าที่ต้องเป็นของจริง** ค่า IOC ค่าแอลฟา จำนวนผู้ทดลองใช้ รายชื่อและคุณวุฒิผู้เชี่ยวชาญ ต้องมาจากงานจริงของผู้วิจัย ถ้ายังไม่ได้ทำ ให้เขียนขั้นตอนไว้และเว้นค่าด้วยตัวยึดตำแหน่ง

## 4. เกณฑ์แปลผลมาตราส่วนประมาณค่า

ความกว้างของช่วง = (คะแนนสูงสุด − คะแนนต่ำสุด) / จำนวนระดับ

สำหรับ 5 ระดับ ความกว้าง = (5 − 1) / 5 = 0.80

| ค่าเฉลี่ย | ระดับ (ตัวอย่างสำหรับความคิดเห็น) |
|---|---|
| 4.21 - 5.00 | มากที่สุด |
| 3.41 - 4.20 | มาก |
| 2.61 - 3.40 | ปานกลาง |
| 1.81 - 2.60 | น้อย |
| 1.00 - 1.80 | น้อยที่สุด |

ใช้ชื่อระดับให้ตรงกับสิ่งที่วัด (เห็นด้วย พึงพอใจ ปฏิบัติ) ถ้าใช้ระดับอื่น (เช่น 4 หรือ 7 ระดับ) ให้คำนวณช่วงใหม่

## 5. เลือกสถิติให้ตรงกับวัตถุประสงค์

| ต้องการ | สถิติที่มักใช้ | ตรวจข้อตกลงเบื้องต้นอะไร |
|---|---|---|
| บรรยายข้อมูล | ความถี่ ร้อยละ ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน | ระดับการวัดของตัวแปร |
| เปรียบเทียบ 2 กลุ่มอิสระ | t-test (independent) / Mann-Whitney U | การแจกแจงปกติ ความแปรปรวนเท่ากัน |
| เปรียบเทียบก่อน-หลัง | paired t-test / Wilcoxon | การแจกแจงของผลต่าง |
| เปรียบเทียบมากกว่า 2 กลุ่ม | One-way ANOVA (+ post hoc) / Kruskal-Wallis | ปกติ ความแปรปรวนเท่ากัน |
| ควบคุมตัวแปรร่วม | ANCOVA | ความชันถดถอยเท่ากัน |
| ความสัมพันธ์ของตัวแปรต่อเนื่อง | Pearson / Spearman | ความเป็นเส้นตรง การแจกแจง |
| ตัวแปรเชิงกลุ่มสองตัว | Chi-square | จำนวนคาดหวังในแต่ละช่อง |
| ทำนายหรืออธิบายปัจจัย | ถดถอยพหุคูณ / ถดถอยโลจิสติก | multicollinearity ความเป็นอิสระของส่วนเหลือ |
| โครงสร้างองค์ประกอบ / โมเดลเหตุ-ผล | EFA, CFA, SEM | ขนาดตัวอย่าง ความเหมาะสมของโมเดล |

เกณฑ์นัยสำคัญที่พบบ่อยคือ .05 ให้ตัดสินใจเลือกสถิติก่อนเก็บข้อมูลและบอกเหตุผล ถ้าข้อมูลไม่ผ่านข้อตกลงเบื้องต้น ให้ใช้สถิติไม่อิงพารามิเตอร์หรือวิธีที่ทนทานกว่า และอธิบายในบทที่ 3 หรือ 4

## 6. การรายงานผลสถิติ

- รายงานค่าสถิติและองศาเสรี เช่น t(58) = 2.34, p = .023 และขนาดอิทธิพลเมื่อทำได้ (Cohen's d, η², R²)
- ระบุทิศทางของความต่าง ไม่ใช่แค่ "มีนัยสำคัญ"
- รูปแบบตารางตามคู่มือสถาบันและข้อกำหนดงาน หากเลือก APA จึงใช้ชื่อตารางด้านบนและเส้นแนวนอนเท่าที่จำเป็น ไม่ตัดเส้นกรอบในตัวอย่าง สจล. เพียงเพราะกฎ APA ทศนิยมต้องเหมาะกับค่าที่รายงานและสม่ำเสมอ
- หากเลือกการรายงานแบบ APA ค่า p ใช้รูป p = .023 หรือ p < .001 ไม่ใส่ 0 นำหน้า; รูปแบบนี้ไม่ใช่การเลือก APA ให้ทั้งเล่มโดยอัตโนมัติ
- แยกการรายงานกับการตีความตามบท/หัวข้อที่ตกลง (ตัวอย่างโครง 5 บทมักอยู่บทที่ 4 และ 5) ไม่กำหนดเลขบทแทนคู่มือของงานนั้น

## 7. งานเชิงคุณภาพ

- **ผู้ให้ข้อมูลหลัก** บอกเกณฑ์การเลือก จำนวน และเหตุผลที่เพียงพอ (เช่น ข้อมูลอิ่มตัว) ไม่ใช้เกณฑ์จำนวนตายตัว
- **เครื่องมือ** แนวคำถามสัมภาษณ์กึ่งโครงสร้าง ตรวจโดยผู้เชี่ยวชาญ ทดลองสัมภาษณ์
- **การวิเคราะห์** การวิเคราะห์เชิงเนื้อหา หรือเชิงประเด็น (thematic analysis) ระบุขั้นตอน การให้รหัส และการจัดกลุ่ม
- **ความน่าเชื่อถือ** ตามกรอบของ Lincoln & Guba ได้แก่ ความน่าเชื่อถือ (credibility) การถ่ายโอนได้ (transferability) ความพึ่งพาได้ (dependability) และความยืนยันได้ (confirmability) เทคนิคที่ใช้ เช่น การตรวจสอบสามเส้า การให้ผู้ให้ข้อมูลตรวจผล การบันทึกร่องรอยการตัดสินใจ
- **บทบาทและอคติของผู้วิจัย** เขียนบอกตรง ๆ ว่าผู้วิจัยมีตำแหน่งแห่งที่อย่างไรต่อเรื่องที่ศึกษา

## 8. จริยธรรมการวิจัย

- งานที่เก็บข้อมูลจากมนุษย์ต้องขอรับรองจากคณะกรรมการจริยธรรมการวิจัยในมนุษย์ของสถาบันก่อนเก็บข้อมูล
- ใช้เอกสารชี้แจงผู้เข้าร่วมและหนังสือแสดงความยินยอม ระบุสิทธิ์ถอนตัว การรักษาความลับ และที่เก็บข้อมูล
- ข้อมูลส่วนบุคคลต้องเก็บและใช้ตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล ลดข้อมูลที่ระบุตัวตนให้เหลือเท่าที่จำเป็น
- เลขรับรองและวันที่รับรองเป็นข้อมูลจริงเท่านั้น ใส่ `[ใส่เลขรับรองจริง]` ถ้ายังไม่มี
