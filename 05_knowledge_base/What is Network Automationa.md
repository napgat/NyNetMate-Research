**Network Automation** คือการนำซอฟต์แวร์และกระบวนการต่างๆ มาทำงานร่วมกัน เพื่อใช้ในการจัดเตรียม (Provision), ตั้งค่า (Configure) และจัดการอุปกรณ์เครือข่ายทั้งหมด ทั้งที่เป็นอุปกรณ์จริง (Physical) และอุปกรณ์เสมือน (Virtual) ภายในเครือข่ายขององค์กร

### 5 ขั้นตอนในการทำ Network Automation

1. **การจัดทำรายการอุปกรณ์ (Take Inventory):** ขั้นตอนแรกคือการสำรวจและระบุอุปกรณ์ทั้งหมดในองค์กร (Inventory and Discovery) ไม่ว่าจะเป็น Desktop, Laptop, อุปกรณ์พกพา (รวมถึง BYOD), อุปกรณ์เครือข่าย เช่น Router, Switch, อุปกรณ์ IoT และฮาร์ดแวร์สำนักงานอื่นๆ เพื่อให้เห็นภาพรวมของโครงสร้างพื้นฐานทั้งแบบใช้สายและไร้สายทั้งหมด
    
2. **การเลือกแพลตฟอร์ม (Choose a Network Automation Platform):** ทีม IT ระดับบริหารต้องประเมินและคัดเลือกแพลตฟอร์มที่เหมาะสม เนื่องจากเครือข่ายส่วนใหญ่ในองค์กรถูกสร้างขึ้นแบบ Manual หรือเป็นระบบที่พัฒนาขึ้นเอง (Homegrown) การเลือกแพลตฟอร์มจึงต้องพิจารณาจากปัจจัยด้าน:
    
    - ความสามารถพื้นฐาน (Out-of-the-box features)
        
    - ความสามารถในการขยายตัว (Extensibility)
        
    - การสนับสนุนทางเทคนิค (Support)
        
3. **การกำหนดนโยบาย (Devise Policies):** การทำระบบอัตโนมัติจำเป็นต้องมีการกำหนดนโยบายและแนวปฏิบัติที่ชัดเจนก่อนการปรับใช้งาน (Deployment) เช่น กฎการเชื่อมต่อ Wi-Fi สาธารณะ หรือนโยบายความปลอดภัยต่างๆ เพื่อให้ระบบตรวจสอบความถูกต้องได้ (Audit)
    
4. **การปรับใช้งานทีละขั้นตอน (Roll Out Gradually):** แนะนำให้เริ่มใช้ระบบอัตโนมัติในลักษณะเป็นเฟส (Staged approach) เช่น เริ่มต้นจากการทำให้การตั้งค่าอุปกรณ์ใหม่ (New device setup) เป็นระบบอัตโนมัติก่อน หรือเลือกทดสอบในสาขาใดสาขาหนึ่งก่อนเป็นแห่งแรก เพื่อปรับปรุงและประเมินผลอย่างต่อเนื่อง
    
5. **การตรวจสอบและปรับปรุง (Troubleshoot and Iterate):** เมื่อระบบเครือข่ายเข้าสู่สภาวะอัตโนมัติมากขึ้น การแก้ไขปัญหาและปรับปรุงจะกลายเป็นกระบวนการปกติ (Change management) ที่ต้องทำอย่างต่อเนื่อง โดยต้องมีการสื่อสารกับผู้บริหารระดับสูงให้ทราบถึงความคืบหน้าของโครงการอยู่เสมอ

ประโยชน์ของการปรับใช้ระบบเครือข่ายอัตโนมัติ (Network Automation) มี 5 ประการหลัก ดังนี้
- **ลดความเสี่ยง (Reduce risk):** ช่วยลดความผิดพลาดจากมนุษย์ (Human error) ซึ่งเป็นสาเหตุหลักของการเกิดข้อมูลรั่วไหล (Data breach) รวมทั้งช่วยควบคุมกระบวนการด้าน Compliance (เช่น มาตรฐาน PCI) และจัดการอัปเดตแพตช์ความปลอดภัยในปริมาณมากได้แบบอัตโนมัติ
    
- **ปรับเปลี่ยนได้รวดเร็ว (Make quicker changes):** ทำให้การแก้ไขหรือปรับแต่งเครือข่ายทำได้บ่อยขึ้น ระบบสามารถปรับการทำงานตามความต้องการของธุรกิจหรือผู้ใช้งานได้แบบไดนามิก เช่น การสลับเส้นทางแบนด์วิดท์สำหรับแอปพลิเคชันวิดีโออัตโนมัติ
    
- **เครือข่ายมีความน่าเชื่อถือมากขึ้น (More reliable network):** ระบบเรียนรู้ที่จะคาดการณ์และป้องกันปัญหาล่วงหน้า ผ่านการรวบรวมข้อมูลจาก Router, Switch และ Log ต่างๆ เพื่อนำมาวิเคราะห์และจัดสรรทรัพยากรให้มีประสิทธิภาพ
    
- **เพิ่มประสิทธิภาพสูงสุด (Optimize performance):** มีเครื่องมือสนับสนุนและตรวจสอบเพื่อแจ้งเตือนผู้ดูแลระบบเมื่อเกิดปัญหา โดยสามารถจัดการทุกอย่างได้ผ่านแดชบอร์ดส่วนกลาง พร้อมระบบวิเคราะห์เพื่อประเมินสถานะเครือข่าย
    
- **ลดความซับซ้อนในการจัดการ (Simplify network management):** การตั้งค่า (Configurations) สามารถทำเป็นมาตรฐานเดียวกันและปรับใช้ครอบคลุมทั้งโครงสร้างพื้นฐานได้โดยใช้แรงงานน้อยลง ทำให้จัดการอุปกรณ์เครือข่ายและ IoT ทั้งหมดได้รวดเร็วและรองรับการขยายขนาด (Scale) ได้ง่ายขึ้น

- **ผลกระทบ:** ทำให้เกิดข้อผิดพลาดในการตั้งค่า (Configuration errors) ความไม่สอดคล้องกันของระบบ และส่งผลให้ต้นทุนการดำเนินงาน (Operational costs) สูงกว่าต้นทุนของตัวเครือข่ายเองถึง 2-3 เท่า

**2. องค์ประกอบที่ลึกขึ้นในขั้นตอนการทำงาน** เมื่อเทียบกับหลักการทั่วไปของ Fortinet ทาง Cisco ได้ระบุกระบวนการที่เน้นการนำไปสร้างระบบ (System Implementation) ไว้ชัดเจนขึ้น:

- **การออกแบบและค้นหา (Network Design):** นอกจากการระบุอุปกรณ์ (Inventory) ยังต้องครอบคลุมถึงการทำ **Topology** เพื่อให้เห็นแผนผังการเชื่อมต่อทั้งหมด ซึ่งเป็นส่วนสำคัญที่ระบบค้นหาเครือข่าย (Network Discovery) ควรทำได้
    
- **การจัดการภาพรวมซอฟต์แวร์ (Software Image Management - SWIM):** การทำ Provisioning ไม่ใช่แค่การตั้งค่า (Config) แต่รวมถึงการจัดการเวอร์ชันของ Firmware และ OS บนอุปกรณ์เครือข่าย (เช่น Cisco IOS) ให้เป็นเวอร์ชันที่ได้มาตรฐานตรงกันทั้งหมด
    
- **การจัดการตลอดวงจรชีวิต (Automated Lifecycle Management):** การทำให้ระบบอัปเกรด แพตช์ และอัปเดตความปลอดภัยทำงานได้อย่างรวดเร็วและแม่นยำ

**3. แนวคิดขั้นสูง (Advanced Networking Concepts)**

- **Intent-based networking (IBN) และ Closed-loop automation:** แนวคิดในการบริหารจัดการที่ผู้ดูแลระบบเพียงแค่กำหนด "ผลลัพธ์ที่ต้องการ" (Intent/Policy) จากนั้นระบบอัตโนมัติจะนำไปตั้งค่า และมีการตรวจสอบตัวเองอยู่เสมอ (Closed-loop) เพื่อปรับปรุงและรักษาสถานะเครือข่ายให้ตรงกับที่กำหนดไว้ตลอดเวลา

# What is network automation?
### 1. นิยามและจุดประสงค์หลัก

- **Network Automation** คือกระบวนการที่ทำให้การตั้งค่า (configuration), การจัดการ (management), การทดสอบ (testing), การติดตั้ง (deployment) และการดำเนินงานของอุปกรณ์เครือข่ายทั้งแบบกายภาพ (physical) และแบบเสมือน (virtual) ทำงานได้โดยอัตโนมัติ
    
- ช่วยลดเวลา ความพยายาม และงบประมาณที่ต้องใช้ในการจัดการและจัดเตรียมระบบเครือข่าย ทำให้สามารถอัปเกรดและติดตั้งบริการต่างๆ ได้รวดเร็วยิ่งขึ้น
### 2. ข้อจำกัดของการจัดการเครือข่ายแบบเดิม

- แม้เทคโนโลยีเครือข่ายจะพัฒนาไปมาก แต่แนวทางปฏิบัติในการจัดการระบบส่วนใหญ่ยังคงไม่เปลี่ยนแปลงมานานหลายทศวรรษ โดยยังพึ่งพากระบวนการแบบ Manual (ทำด้วยมือ) เป็นหลัก
    
- การจัดการแบบ Manual มีความยุ่งยาก เกิดข้อผิดพลาดได้ง่าย (error-prone) และไม่เพียงพอต่อการรองรับความต้องการของเวิร์กโหลดในปัจจุบันที่มีความผันผวนและคาดเดาไม่ได้
### 3. สิ่งที่ระบบอัตโนมัติเข้ามาช่วยจัดการ

- **ทำงานแทนในส่วนงานรูทีน:** ระบบจะเข้ามาดำเนินการโดยอัตโนมัติในส่วนของการตั้งค่า, การทดสอบเครือข่าย, การจัดเตรียมทรัพยากร (resource provisioning), การทำโหลดบาลานซ์ (load balancing) และการทำ workflow deployment
    
- **ลดต้นทุนและเพิ่มนวัตกรรม:** ลดความต้องการด้านบุคลากรในงานซ่อมบำรุงที่ต้องทำซ้ำๆ ทำให้องค์กรลดต้นทุนการดำเนินงานลงได้ และช่วยให้ทีม IT มีเวลาไปโฟกัสกับการสร้างนวัตกรรมใหม่ๆ
    
- **สร้างความสม่ำเสมอและความปลอดภัย:** ระบบอัตโนมัติช่วยให้การตั้งค่าและนโยบายเครือข่ายถูกนำไปใช้งานอย่างสม่ำเสมอเหมือนกันทั่งทั้งระบบ ลดความเสี่ยงในการเกิดเครือข่ายล่ม (network outages) และปัญหาความปลอดภัยที่มีสาเหตุมาจากความผิดพลาดของมนุษย์ (human error)
    
- **เพิ่มประสิทธิภาพโดยรวม:** ยกระดับทั้งในด้านการเชื่อมต่อ, ความเร็วในการทำงาน, ความยืดหยุ่นในการฟื้นฟูระบบ (resiliency), ความคล่องตัว (agility) และการใช้ทรัพยากรเครือข่ายให้คุ้มค่าที่สุด

## How does network automation work?

### 1. การทำงานผ่าน Command Line Interface (CLI)

- **การใช้ Operator:** ผู้ดูแลระบบเครือข่ายสามารถใช้สัญลักษณ์หรืออักขระพิเศษเพื่อสร้างและรันเหตุการณ์ตามลำดับ (Event sequences) โดยอ้างอิงจากความสำเร็จหรือความล้มเหลวของคำสั่งก่อนหน้า
    
- **การใช้ Shell Scripts:** สามารถรวบรวมรายการคำสั่งต่างๆ ลงในไฟล์ข้อความ (Text files) เพื่อให้ CLI สามารถรันหลายคำสั่งพร้อมกันได้ผ่าน Command line เดียว
### 2. การทำงานผ่าน Software Layer

- **การจัดการผ่าน UI:** ซอฟต์แวร์จะแปลงงานเครือข่ายให้เป็นโปรแกรมที่พร้อมใช้งาน ซึ่งสามารถเลือก ตั้งเวลา และสั่งการ (Deploy) ได้ง่ายผ่าน User Interface
    
- **การทำงานผ่าน API:** ใช้ Application Programming Interfaces (APIs) ในการสื่อสารกับฮาร์ดแวร์และอุปกรณ์เครือข่ายที่อยู่กระจัดกระจาย ทั้งใน On-premises data centers, Public cloud, Private cloud รวมถึงสภาพแวดล้อมแบบ Hybrid และ Multicloud
    
- **การใช้ Playbooks:** ซอฟต์แวร์สามารถจัดการสิทธิ์และการตั้งค่าอุปกรณ์แบบอัตโนมัติ โดยการจัดระเบียบรายการอุปกรณ์ (Inventories), โมดูล, ปลั๊กอิน และ API endpoints ให้อยู่ในรูปแบบของ Playbooks ที่สามารถค้นหาและนำไปใช้งานข้ามผู้ให้บริการ (Service providers) ได้
### 3. การผสานรวม AI และ Machine Learning (ML)

- **AI Engine:** ช่วยประเมินประสิทธิภาพของเครือข่ายและแอปพลิเคชัน และทำการปรับเปลี่ยนการตั้งค่า (Configurations) ให้โดยอัตโนมัติตามความจำเป็น
    
- **Machine Learning:** ทำหน้าที่วิเคราะห์การใช้แบนด์วิดท์และแนวโน้มประสิทธิภาพ เพื่อตั้งค่าอุปกรณ์เครือข่ายทั้งแบบ Physical และ Virtual ตามพารามิเตอร์ที่กำหนดไว้ นอกจากนี้ ML ยังเรียนรู้จากเหตุการณ์ในอดีต ทำให้ระบบสามารถแก้ไขปัญหาได้รวดเร็วและแม่นยำขึ้นเมื่อเวลาผ่านไป

โดยทั่วไป กลยุทธ์ในการทำ Network Automation มักจะเป็นการผสมผสานประโยชน์ของทั้งรูปแบบ **Software-driven** และ **CLI-based** เข้าด้วยกัน เพื่อสร้างเครือข่ายคอมพิวเตอร์ที่มีความเร็วสูงและมีความพร้อมใช้งาน (High-availability) สูงสุดครับ
## รูปแบบของการทำระบบเครือข่ายอัตโนมัติ (Types of network automation)

1. **Orchestration automation:** เน้นจัดการกระบวนการที่ซับซ้อนซึ่งต้องอาศัยการทำงานร่วมกันจากหลายระบบและหลายอุปกรณ์ เช่น การเชื่อมต่อแอปพลิเคชันแบบกระจายศูนย์ (Distributed applications) เพื่อให้ข้อมูลไหลเวียนได้เร็วขึ้นและลดข้อผิดพลาด

2. **Provisioning automation:** ช่วยเพิ่มอุปกรณ์ใหม่เข้าสู่เครือข่าย โดยระบบจะผสานรวมอุปกรณ์และจัดการการตั้งค่า (Configurations) ที่จำเป็นทั้งหมดให้โดยอัตโนมัติ

3. **Script-driven network automation:** การใช้สคริปต์ที่เขียนด้วยภาษาโปรแกรม (ในปัจจุบันนิยมใช้ภาษาแบบ Open-source เช่น Python) เพื่อสั่งให้ระบบทำงานเพื่อตอบสนองต่อเงื่อนไข (Triggers) ที่กำหนด

4. **Software-based network automation:** หรือเรียกอีกอย่างว่า Intelligent network automation เป็นการทำงานผ่านพอร์ทัลผู้ดูแลระบบเพื่อสั่งรันงานต่างๆ โดยไม่ต้องเขียนสคริปต์แบบ Manual มักจะมี Template มาให้เพื่อสร้างการทำงานตามนโยบายเครือข่าย

5. **Intent-based network automation:** เป็นรูปแบบขั้นสูงที่ใช้ AI และ ML เพื่อทำความเข้าใจความต้องการของผู้ใช้และธุรกิจ จากนั้นระบบจะปรับใช้และรักษาระดับประสิทธิภาพของเครือข่ายให้ตรงตามเป้าหมาย (Service levels) ที่ตั้งไว้โดยอัตโนมัติ

6. **Network security automation:** การใช้เครื่องมือความปลอดภัยร่วมกับ AI/ML เพื่อจัดการงานต่างๆ แบบอัตโนมัติ เช่น การสแกนช่องโหว่ การตรวจจับการบุกรุก (Intrusion detection) การรับมือกับเหตุการณ์ (Incident response) และการอัปเดตแพตช์

7. **Load balancing and failover:** การจัดการกระจายโหลดการทำงานของเซิร์ฟเวอร์โดยอัตโนมัติ เพื่อให้ระบบสำรอง (Failover) สามารถสลับการทำงานขึ้นมาตอบสนองได้อย่างรวดเร็วเมื่อเกิดปัญหา ทำให้แอปพลิเคชันทำงานได้เต็มประสิทธิภาพเสมอ

คุณสมบัติหลักของเครื่องมือจัดการเครือข่ายอัตโนมัติ (Features of network automation tools) ซึ่งในปัจจุบันมักใช้พื้นฐานจากหลักการของ AIOps มีดังนี้ครับ:

1. **การจัดการการตั้งค่า (Configuration management):** สามารถติดตั้ง (Deploy) อัปเดต และสำรองข้อมูลการตั้งค่าของอุปกรณ์เครือข่ายแต่ละตัวได้โดยอัตโนมัติ ช่วยสร้างความสม่ำเสมอตั้งแต่ต้นทางถึงปลายทาง และสามารถย้อนคืนค่า (Rollback) ได้อย่างรวดเร็วเมื่อจำเป็น

2. **การจัดเตรียมทรัพยากร (Provisioning):** รองรับระบบ Zero-touch provisioning ที่อุปกรณ์จะได้รับการตั้งค่าโดยอัตโนมัติทันทีที่ถูกนำมาเชื่อมต่อกับเครือข่าย ช่วยเร่งความเร็วในการเปิดใช้งานบริการใหม่ๆ

3. **การทำเวิร์กโฟลว์อัตโนมัติ (Workflow automation):** จัดการงานประจำหรือกระบวนการที่ซับซ้อนให้เป็นไปโดยอัตโนมัติ เช่น การวินิจฉัยเครือข่าย (Network diagnostics) หรือการอัปเดตซอฟต์แวร์

4. **การตรวจสอบและแจ้งเตือน (Monitoring and alerts):** ติดตามการใช้แบนด์วิดท์ สถานะการทำงานของอุปกรณ์ และรูปแบบทราฟฟิกอย่างต่อเนื่อง โดยจะแจ้งเตือนเมื่อระบบทำงานถึงเกณฑ์ที่กำหนดไว้หรือเมื่อตรวจพบความผิดปกติ (Anomaly) ทำให้ทีมสามารถแก้ไขปัญหาก่อนที่จะส่งผลกระทบต่อผู้ใช้งาน

5. **การวิเคราะห์ข้อมูลและการแก้ปัญหาเชิงคาดการณ์ (Data analysis and predictive problem-solving):** วิเคราะห์สถานะเครือข่ายแบบเรียลไทม์ด้วยอัลกอริทึม AI และ ML เพื่อประเมินและคาดการณ์ปัญหาล่วงหน้า เช่น ถ้าระบบคาดการณ์ว่าทราฟฟิกข้อมูลกำลังจะพุ่งสูงขึ้น ระบบสามารถเปลี่ยนเส้นทางทราฟฟิกไปที่เซิร์ฟเวอร์อื่นเพื่อกระจายโหลดได้ล่วงหน้า

6. **การจัดการปัญหาด้วยตนเอง (Autonomous solution implementation):** ช่วยสร้างเครือข่ายที่สามารถฟื้นฟูตัวเองได้ (Self-healing networks) ผ่านการทำงานแบบ Closed-loop automation เมื่อระบบพบปัญหา จะสามารถปรับการตั้งค่า ลงแพตช์ หรือเปลี่ยนเส้นทางทราฟฟิกได้อัตโนมัติเพื่อลด Downtime
7. **การเรียนรู้และปรับตัวอย่างต่อเนื่อง (Continuous learning and adaptation):** ซอฟต์แวร์จะเรียนรู้จากสิ่งที่เกิดขึ้นในเครือข่ายอย่างต่อเนื่อง เพื่อนำมาปรับปรุงอัลกอริทึมและกลยุทธ์การทำงานให้ระบบมีความยืดหยุ่นและพร้อมรองรับความต้องการที่เปลี่ยนแปลงอยู่เสมอ

ประโยชน์ของการทำระบบเครือข่ายอัตโนมัติ (Benefits of network automation) มี 5 ประการหลัก ดังนี้
- **เพิ่มประสิทธิภาพของเครือข่าย (Increased network efficiency):** ลดเวลาและแรงงานในการจัดการและจัดเตรียมเครือข่าย (Provisioning) กระบวนการตั้งค่า ติดตั้ง และทดสอบสามารถทำได้รวดเร็วและอัตโนมัติ ทำให้ทีม IT มีเวลาไปมุ่งเน้นงานเชิงกลยุทธ์มากขึ้น
    
- **บังคับใช้นโยบายอย่างต่อเนื่อง (Continuous policy enforcement):** เครื่องมืออัตโนมัติสามารถนำไปใช้และบังคับใช้นโยบาย (Policies) ครอบคลุมทั้งโครงสร้างพื้นฐาน ช่วยให้มั่นใจว่าอุปกรณ์ทุกเครื่องมีการอัปเดตความปลอดภัยและใช้มาตรฐานการทำงานเดียวกัน
    
- **ขยายขนาดได้ง่ายขึ้น (Easier scaling):** รองรับการเติบโตขององค์กรได้อย่างราบรื่น ช่วยให้เครือข่ายจัดการกับปริมาณงานที่เพิ่มขึ้นได้โดยไม่ต้องเพิ่มภาระงานให้ผู้ดูแลระบบตามสัดส่วน
    
- **ลดต้นทุนการดำเนินงาน (Lower operating costs):** การให้ระบบอัตโนมัติจัดการงานที่ต้องทำซ้ำๆ ช่วยลดความจำเป็นในการใช้แรงงานแบบ Manual ทำให้ลดค่าใช้จ่ายในการดำเนินงานด้านเครือข่ายลงได้
    
- **ยกระดับความปลอดภัยเครือข่าย (Better network security):** ช่วยยกระดับความปลอดภัยผ่านการทำระบบตรวจจับ (Detection) การตอบสนองต่อเหตุการณ์ (Incident response) และการจัดการแพตช์ (Patch management) แบบอัตโนมัติ ซึ่งช่วยเสริมความแข็งแกร่งและลดความเสี่ยงโดยรวม

ทิศทางในอนาคตของระบบเครือข่ายอัตโนมัติจะมุ่งเน้นไปที่การสร้างเครือข่ายที่รวดเร็ว ไดนามิก และสามารถปรับตัวตามความต้องการทางธุรกิจที่เปลี่ยนแปลงตลอดเวลาได้ โดยมีเทรนด์สำคัญดังนี้ครับ:

- **การผสาน AI และ ML:** จะถูกนำมาใช้เพื่อสร้างเครือข่ายที่สามารถฟื้นฟูตัวเองได้ (Self-healing networks) ซึ่งสามารถแก้ไขปัญหาเชิงรุกและปรับการทำงานตามสภาพแวดล้อมทั้งแบบดั้งเดิม, Cloud-native และ Edge computing
    
- **Edge computing และการทำงานร่วมกับ IoT:** เนื่องจากข้อมูลถูกประมวลผลใกล้กับจุดกำเนิดมากขึ้น เครื่องมือระบบอัตโนมัติยุคใหม่จึงต้องถูกพัฒนาให้สามารถจัดการกับสภาพแวดล้อมแบบกระจายศูนย์ (Decentralized environments) เพื่อเพิ่มความรวดเร็วในการประมวลผล
    
- **Infrastructure as Code (IaC):** การใช้โค้ด (Code) ระดับสูงเพื่อกำหนดและจัดการโครงสร้างพื้นฐานเครือข่ายโดยอัตโนมัติ ซึ่งจะช่วยให้วิศวกรสามารถปรับปรุงเวิร์กโฟลว์, ระบบควบคุมเวอร์ชัน (Version control) และสร้างเครือข่ายที่ปรับขยายขนาด (Scale) ได้อย่างคล่องตัว
    
- **ทางเลือกในการจัดการแบบ Multi-vendor:** ระบบอัตโนมัติกำลังมุ่งไปสู่โซลูชันที่เป็นกลาง (Vendor-agnostic) ที่สามารถทำงานร่วมกับเครื่องมือ Third-party และรองรับสถาปัตยกรรมที่ประกอบด้วยอุปกรณ์จากหลากหลายผู้ผลิต (Multi-vendor architectures) แบบรวมศูนย์ เพื่อขจัดข้อจำกัดในการผูกติดกับโครงสร้างพื้นฐานของแบรนด์ใดแบรนด์หนึ่ง
    
- **Zero-trust security:** การบังคับใช้หลักการ Zero-trust ที่ควบคุมการเข้าถึง กฎการยืนยันตัวตน (Authentication) และโปรโตคอลการเข้ารหัสอย่างเข้มงวด เพื่อปกป้องเครือข่ายอัตโนมัติที่มีการกระจายตัวสูงจากภัยคุกคามทางไซเบอร์
    
- **การสนับสนุนโครงข่าย 5G:** ระบบอัตโนมัติจะเข้ามาจัดการความซับซ้อนของ 5G โดยเฉพาะในเรื่องของการทำ Network Slicing (การแบ่งโครงสร้างพื้นฐานทางกายภาพออกเป็นเครือข่ายเสมือนย่อยๆ) และการจัดการทรัพยากรแบบไดนามิก เพื่อให้รองรับความต้องการใช้งานที่หลากหลายในแต่ละอุตสาหกรรม
