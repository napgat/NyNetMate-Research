# Course Overview

ภาพรวมรายวิชา โครงงาน 1 และ โครงงาน 2

## 01076311 Project 1

**รายละเอียดวิชา (Course Description)**
- การทำโครงงานหรืองานวิจัยในหัวข้อที่เกี่ยวข้องกับวิศวกรรมคอมพิวเตอร์ภายใต้การดูแลของอาจารย์ที่ปรึกษา
- ในระหว่างภาคการศึกษามีการเสนอรายงานความคืบหน้าของงานอย่างสม่ำเสมอ
- เมื่อสิ้นภาคการศึกษานักศึกษาจะต้องส่งรายงานและบทสรุปของงาน
- พร้อมทั้งนำเสนอต่อคณะกรรมการสอบ

**ผลลัพธ์ (Output)**
1. **รายงานโครงงาน**
   - เนื้อหาเป็นไปตามมาตรฐานที่กำหนด
   - เรียบเรียงถ้อยคำให้อ่านง่าย ตามฉันทลักษณ์การเขียน
   - รูปแบบเป็นไปตามปริญญานิพนธ์ที่ผู้ประสานงานวิชาโครงงานกำหนด
   - ผ่านการพิจารณาจากอาจารย์ที่ปรึกษา
2. **การนำเสนอโครงงาน**
   - หัวข้อ ที่มาของโครงงาน และ วัตถุประสงค์โครงงาน
   - ทฤษฎีที่นำมาประยุกต์ใช้ และ เครื่องมือ
   - การออกแบบ (ครอบคลุมทั้งรายวิชาโครงงาน 1 และ 2)
   - การทดลอง
   - สรุปผล

## 01076312 Project 2

**รายละเอียดวิชา (Course Description)**
- การทำโครงงานหรืองานวิจัยที่ต่อเนื่องจากวิชา 01076311 โครงงาน 1 ให้สำเร็จ
- ในระหว่างภาคการศึกษามีการเสนอรายงานความคืบหน้าของงานอย่างสม่ำเสมอ
- เมื่อสิ้นภาคการศึกษานักศึกษาจะต้องส่งผลงานที่สำเร็จและปริญญานิพนธ์ฉบับสมบูรณ์
- พร้อมทั้งนำเสนอผลงาน และสาธิตผลงานต่อคณะกรรมการสอบ

   - เรียบเรียงถ้อยคำให้อ่านง่าย ตามฉันทลักษณ์การเขียน
   - รูปแบบเป็นไปตามปริญญานิพนธ์ที่ผู้ประสานงานวิชาโครงงานกำหนด
   - ผ่านการพิจารณาจากอาจารย์ที่ปรึกษา และ กรรมการสอบ
2. **การนำเสนอโครงงาน**
   - หัวข้อ ที่มาของโครงงาน และ วัตถุประสงค์โครงงาน
   - ทฤษฎีที่นำมาประยุกต์ใช้ และ เครื่องมือ
   - การออกแบบ
   - การทดลอง/การทดสอบ
   - สรุปผล
