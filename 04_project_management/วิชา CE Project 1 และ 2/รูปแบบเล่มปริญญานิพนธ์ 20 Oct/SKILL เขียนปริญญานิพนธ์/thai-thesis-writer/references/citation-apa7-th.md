# คู่มือการอ้างอิงและบรรณานุกรม (APA ฉบับที่ 7 สำหรับงานภาษาไทย)

ใช้ไฟล์นี้เมื่อเลือก APA 7 สำหรับงานนั้นแล้วเท่านั้น ไม่ใช้เป็นค่าเริ่มต้นเมื่อยังไม่ทราบระบบอ้างอิง สถาบันอาจปรับรายละเอียด เช่น ระบบปีและการเรียงแหล่งไทย/ต่างประเทศ ให้ยึดคู่มือที่ใช้กับงานและบันทึกวิธีอ้างในเนื้อหาแยกจากรูปแบบบรรณานุกรมใน `thesis-state.md`

**ถ้าสถาบันมีรูปแบบบรรณานุกรมของตนเอง** (เช่น สจล. ซึ่งใช้แบบ "ผู้แต่ง. ปี. ชื่อเรื่อง. เมือง : สำนักพิมพ์." ไม่ใช่ APA) ให้ใช้ไฟล์ `format-*.md` ของสถาบันนั้นแทนไฟล์นี้

**ข้อสำคัญ** ตัวอย่างทั้งหมดในไฟล์นี้เป็นชื่อสมมติเพื่อแสดงรูปแบบเท่านั้น ห้ามนำไปใส่ในเล่มเป็นแหล่งอ้างอิงจริง แหล่งในเล่มต้องเป็นแหล่งที่มีจริงและผู้ใช้หรือคุณเปิดตรวจแล้ว

## สารบัญ

1. หลักที่ใช้บ่อยสำหรับงานไทย
2. การอ้างอิงในเนื้อหา
3. รูปแบบรายการในบรรณานุกรม
4. การเรียงลำดับ
5. ขั้นตอนตรวจแหล่งอ้างอิงก่อนใส่ในเล่ม
6. ข้อผิดพลาดที่พบบ่อย

---

## 1. หลักที่ใช้บ่อยสำหรับงานไทย

- ผู้แต่งชาวไทยในเนื้อหาและบรรณานุกรมมักใช้ ชื่อ แล้วตามด้วยนามสกุล เช่น สมชาย ใจดี ส่วนผู้แต่งต่างประเทศใช้นามสกุลก่อน เช่น Smith, J. (บางสถาบันกำหนดต่าง ให้ตรวจคู่มือ)
- แหล่งภาษาไทยใช้ปี พ.ศ. แหล่งต่างประเทศใช้ ค.ศ. (บางสถาบันให้ใช้ ค.ศ. ทั้งหมด หรือให้แปลงเป็น พ.ศ. ทั้งหมด)
- ใช้ "และคณะ" สำหรับแหล่งไทยที่มีผู้แต่งตั้งแต่สามคนขึ้นไป และ "et al." สำหรับแหล่งต่างประเทศ
- ลิงก์ DOI ใช้รูป https://doi.org/... ถ้ามี

## 2. การอ้างอิงในเนื้อหา

**แบบวงเล็บท้ายประโยค** ใช้เมื่อเน้นข้อเท็จจริง

- ผู้แต่งคนเดียว (ไทย): (สมชาย ใจดี, 2565)
- สองคน (ไทย): (สมชาย ใจดี & มาลี รักเรียน, 2565) หรือใช้ "และ" ตามคู่มือสถาบัน
- สามคนขึ้นไป (ไทย): (สมชาย ใจดี และคณะ, 2565)
- ต่างประเทศคนเดียว: (Smith, 2020)
- ต่างประเทศสองคน: (Smith & Jones, 2020)
- ต่างประเทศสามคนขึ้นไป: (Smith et al., 2020)
- หลายแหล่งในวงเล็บเดียว: (Smith, 2020; สมชาย ใจดี, 2565) เรียงตามอักษรผู้แต่ง
- ระบุหน้าเมื่ออ้างตรง: (Smith, 2020, p. 45) หรือ (สมชาย ใจดี, 2565, น. 45)

**แบบเน้นผู้แต่งในประโยค** ใช้เมื่อเน้นผู้แต่งหรือเปรียบเทียบความเห็น

- สมชาย ใจดี (2565) อธิบายว่า...
- Smith (2020) พบว่า...

**การอ้างต่อ (secondary source)** ใช้เฉพาะเมื่อหาต้นฉบับไม่ได้จริง เช่น (Jones, 2015, as cited in Smith, 2020) และลงเฉพาะแหล่งที่อ่านจริง (Smith) ในบรรณานุกรม

**การยกข้อความตรง** ข้อความไม่เกิน 40 คำใช้เครื่องหมายคำพูดในย่อหน้าพร้อมเลขหน้า ข้อความยาวกว่านั้นแยกเป็นบล็อกเยื้องเข้า ใช้เท่าที่จำเป็น งานวิจัยส่วนใหญ่ควรสังเคราะห์ด้วยถ้อยคำของผู้วิจัย

## 3. รูปแบบรายการในบรรณานุกรม

หัวข้อ "บรรณานุกรม" วางกึ่งกลางหน้า ชื่อเรื่องหนังสือ ชื่อวารสาร และเลขปีที่ ใช้ตัวเอียง (ชื่อตัวเอียงในไฟล์ข้อความธรรมดาใช้เครื่องหมาย * ครอบ) แต่ละรายการใช้การเยื้องบรรทัดที่สอง (hanging indent)

**บทความวารสาร (ไทย)**
```
สมชาย ใจดี, และ มาลี รักเรียน. (2565). ชื่อบทความตัวอย่างสมมติ. *วารสารตัวอย่าง, 10*(2), 45-62. https://doi.org/xx.xxxx/xxxxx
```

**บทความวารสาร (ต่างประเทศ)**
```
Smith, J. A., & Jones, B. C. (2020). Title of the example article in sentence case. *Journal of Example Studies, 12*(3), 101-120. https://doi.org/xx.xxxx/xxxxx
```

**หนังสือ (ไทย)**
```
สมชาย ใจดี. (2564). *ชื่อหนังสือตัวอย่างสมมติ* (พิมพ์ครั้งที่ 2). สำนักพิมพ์ตัวอย่าง.
```

**หนังสือ (ต่างประเทศ)**
```
Smith, J. A. (2019). *Title of the example book in sentence case* (2nd ed.). Example Publisher.
```

**วิทยานิพนธ์ / ดุษฎีนิพนธ์ (ไทย)**
```
สมชาย ใจดี. (2563). *ชื่อวิทยานิพนธ์ตัวอย่างสมมติ* [วิทยานิพนธ์ปริญญามหาบัณฑิต, ชื่อมหาวิทยาลัย]. ชื่อฐานข้อมูลหรือคลังวิทยานิพนธ์. URL
```

**เว็บไซต์หรือรายงานหน่วยงาน**
```
ชื่อหน่วยงาน. (2566, 15 มีนาคม). *ชื่อรายงานหรือหน้าเว็บตัวอย่าง*. ชื่อเว็บไซต์. URL
```

**กฎหมายหรือนโยบาย** ลงชื่อกฎหมาย ปี และแหล่งเผยแพร่ ตามคู่มือสถาบัน

**ข้อมูลบรรทัดสำคัญ**
- ถ้าไม่มีปี ใช้ (ม.ป.ป.) สำหรับไทย หรือ (n.d.) สำหรับต่างประเทศ
- ผู้แต่งเป็นหน่วยงาน ใช้ชื่อหน่วยงานเป็นผู้แต่ง
- ผู้แต่งหลายคนในบรรณานุกรม APA 7 ใส่ได้ถึง 20 ชื่อ

## 4. การเรียงลำดับ

- เรียงตามลำดับอักษรของชื่อผู้แต่งตัวแรก
- แยกแหล่งภาษาไทยกับภาษาต่างประเทศเป็นกลุ่มหรือรวมกัน ตามคู่มือสถาบัน (ที่พบบ่อยคือรายการภาษาไทยก่อน แล้วตามด้วยภาษาอังกฤษ)
- ผู้แต่งเดียวกันหลายรายการ เรียงตามปีจากเก่าไปใหม่ ถ้าปีเดียวกันใช้ ก ข หรือ a b ต่อท้ายปี

## 5. ขั้นตอนตรวจแหล่งอ้างอิงก่อนใส่ในเล่ม

เหตุผล คือแหล่งที่สร้างจากความจำหรือที่ไม่มีอยู่จริงทำให้งานเสียหายทั้งเล่ม

1. ได้แหล่งจากผู้ใช้โดยตรง หรือค้นเจอผ่านฐานข้อมูลหรือเครื่องมือค้นหา
2. เปิดหน้าแหล่ง ตรวจว่า ชื่อผู้แต่ง ปี ชื่อเรื่อง ชื่อวารสาร ปีที่ ฉบับที่ หน้า และ DOI ตรงกัน
3. ตรวจว่าเนื้อหาที่จะอ้างมีอยู่ในแหล่งนั้นจริง ไม่ใช่แค่ชื่อเรื่องเกี่ยวข้อง
4. บันทึกลงรายการ "แหล่งที่ยืนยันแล้ว" ในไฟล์สถานะ พร้อมประเด็นที่ใช้อ้าง
5. แหล่งที่ยังไม่ได้ตรวจ ใช้ตัวยึดตำแหน่ง `[ตรวจอ้างอิง: ...]` ในเนื้อหา อย่าใส่ชื่อและปีเดา

เมื่อไม่มีเครื่องมือค้นหา ให้ช่วยผู้ใช้กำหนดคำค้น (ภาษาไทยและอังกฤษ) และฐานข้อมูลที่ควรไปหา ได้แก่ ThaiJO, TCI, ThaiLIS, Google Scholar, Scopus, Web of Science แล้วให้ผู้ใช้นำผลมาให้ตรวจและจัดรูป

## 6. ข้อผิดพลาดที่พบบ่อย

- ใส่ในบรรณานุกรมแต่ไม่ได้อ้างในเนื้อหา หรืออ้างแล้วไม่มีในบรรณานุกรม
- ปีในเนื้อหากับบรรณานุกรมไม่ตรงกัน หรือสลับ พ.ศ. กับ ค.ศ. ภายในเล่ม
- ชื่อผู้แต่งไทยกลับเป็นนามสกุลนำหน้าโดยไม่ตั้งใจ
- ใช้ "et al." กับแหล่งไทย หรือ "และคณะ" กับแหล่งต่างประเทศ
- อ้างต่อโดยไม่ได้อ่านต้นฉบับแต่ลงต้นฉบับในบรรณานุกรม
- ลิงก์เสียหรือไม่มีวันที่เข้าถึงในกรณีที่คู่มือสถาบันกำหนด
